# sanctioned exceptions

Three registers, each holding the argument a reviewer accepted for one kind of exception.

## over-limit units

Every file under `lib/`, `presets/` or `tests/` that exceeds the file ceiling in `CONVENTIONS.md` is
listed here, with the reason splitting it would make the code worse. Nothing else is exempt: an
overage that is not a row below is a defect. A row whose file has since dropped under the ceiling is
stale and is removed. `examples/` is outside the file ceiling entirely and takes no row here, and so
is a record a build step generates and rewrites whole. Functions are held to the same rule in the
register that follows this one, `examples/` included.

This is a reviewed register, not a gate. No build step reads it, and `CONVENTIONS.md` says so; a row
is an argument a reviewer accepted, and it is checked when a change is read.

## over-limit functions

Every function that exceeds the function ceiling in `CONVENTIONS.md` is listed here, with the reason
splitting it would make the code worse. The same rule governs it as governs the register above: an
overage that is not a row below is a defect, and a row whose function has since dropped under the
ceiling is stale and is removed.

The ceiling counts lines as they sit on screen, which is a property of the text rather than of the
language it is written in. A CMake function is therefore held to it exactly as a C++ one is, and a
row here may name either.

This is a reviewed register, not a gate. No build step reads it; a row is an argument a reviewer
accepted, and it is checked when a change is read.

## synchronization primitives

Every object belongs to one strand and is touched only from that strand, and cross-strand access is
a posted handler. A lock is therefore never the discipline by which two strands share an object —
but a primitive is still what a hand-off *across* a boundary is built from, and one of those is
sanctioned here or it stops the configure.

Unlike the register above, this one **is** read: the paths are the allowlist in `lib/CMakeLists.txt`
that `cmake/verify_conventions.cmake` scans against, and an entry naming a file that is gone or that
no longer carries a primitive stops the configure. Every path there has a row here and every row
names a path there.

The scan covers every module the umbrella listfile declares — the Foundation targets and the
extensions alike — so a module added to the tree is policed the moment it is declared and the
per-file allowlist below is the only escape from it. The scan reads this repository's own sources
and reaches no project that writes an extension of its own.

| `lib/praxis-scheduler/src/pool.h` | one `mutex`, two `condition_variable`, `unique_lock` in the private signatures | The strand table is the boundary itself: it is what a caller admits work into and what a worker takes work out of, so the object under the lock *is* the hand-off and there is no second discipline it could be replaced by.
